# 交互直觉性论证表

> 标准：任何一个 8 岁小孩第一次接触这个界面，不需要任何人教，只凭对物理世界的常识就能正确使用。
> 方法：对每个交互问"小孩的直觉期望是什么？我们的实现匹配吗？"——不匹配就改实现，不改直觉。

## Owner中心的内容边界

这些界面交互是既有UI论证，不是owner理解/接受的认证，也不是完整浏览器验收记录。选中、FOCUS、颜色、Done只能展示已记录结构；owner目的、提问/纠正、AI交付与双方剩余责任应由正文有据表达。当前人类owner与已委派的局部AI owner共用模型，不新增理解评分/自动审批；协作方法见owner-collaboration.md。本轮只同步指引，不改变UI实现或以下历史交互记录。

## 一、图交互（画布上的帧卡）

### G-01 悬停帧卡

| | |
|---|---|
| 小孩直觉 | 我用手指着一栋房子 → 我看清楚这栋房子是什么样的，旁边的变暗了，因为我在关注它 |
| 实现 | 悬停帧 → 该帧及其"家族"（祖先+子树）高亮蓝色，其他帧降低透明度 |
| 论证 | 物理直觉完全匹配。小孩指着东西 = 关注它 + 它的关联物。降低不相关事物的亮度 = 聚焦，与手电筒照在黑暗房间里一致 |
| 偏差 | 当前实现高亮的是"子树+焦点路径"，不是"该帧的祖先"。小孩指着二楼，三楼也亮了——这不直觉。**修正：只亮祖先+子树** |

### G-02 单击帧卡

| | |
|---|---|
| 小孩直觉 | 我点了一下玩具 → 我选中了它，可以看它的详细信息 |
| 实现 | 单击帧 → 侧栏显示该帧完整内容（目标/计划/原则/记录），帧卡出现选中光晕 |
| 论证 | 点=选中=看详情，这是所有触屏设备的第一交互。小孩在 iPad 上就是这样学会的 |
| 偏差 | 当前点击后还会自动缩放画布（fit），相当于"我碰了玩具，房间突然移动了"。小孩会觉得房间在乱跳。**修正：选中不移动画布** |

### G-03 双击帧卡

| | |
|---|---|
| 小孩直觉 | 我快速点两下地图上的位置 → 镜头飞过去放大看 |
| 实现 | 双击帧 → 画布平滑动画飞到该帧并放大 |
| 论证 | Google Maps 建立的全球直觉。双击=放大聚焦，这是肌肉记忆 |
| 偏差 | 当前实现禁用了双击缩放（d3 默认），没有利用这个直觉。**修正：双击帧=飞过去** |

### G-04 右键帧卡

| | |
|---|---|
| 小孩直觉 | 我不知道怎么操作这个玩具 → 出来一个"你能对它做什么"的清单 |
| 实现 | 右键帧 → 弹出操作菜单（push 子项 / pop 关闭 / 暂停 / 恢复 / 切换 / 复制引用） |
| 论证 | 右键=选项菜单，这是桌面计算机的普遍直觉。不能做的事变灰色并写原因——就像小孩看到"此门关闭"的标志 |
| 偏差 | 基本正确。但灰色项的说明文字也变灰了，小孩看不清。**修正：操作名灰色，原因文字正常亮度** |

### G-05 拖拽画布

| | |
|---|---|
| 小孩直觉 | 我拖动地图 → 地图跟着我的手移动 |
| 实现 | 按住拖动 → 画布平移 |
| 论证 | 完全匹配。所有地图/画布应用的共同直觉 |
| 偏差 | 无 |

### G-06 滚轮画布

| | |
|---|---|
| 小孩直觉 | 我用两根手指撑开 → 东西变大；捏合 → 变小 |
| 实现 | 滚轮向上=放大，向下=缩小 |
| 论证 | 触屏一代的本能。桌面滚轮方向可能与触屏相反（scroll up = zoom in），这是历史惯例 |
| 偏差 | 无 |

### G-07 点击空白处

| | |
|---|---|
| 小孩直觉 | 我点了一下空地 → 我放下了之前选的东西 |
| 实现 | 点击空白 → 取消选中，侧栏回到帮助提示 |
| 论证 | 点空白=取消选择，所有选择工具的通用直觉（选文件、选文字） |
| 偏差 | 无 |

### G-08 帧卡状态颜色

| | |
|---|---|
| 小孩直觉 | 红灯停、绿灯走、黄灯等、蓝灯=正在进行的 |
| 实现 | 蓝边=当前焦点（TOP）、黄边=暂停等待、绿边=完成、红边=失败、紫边=焦点但在等 |
| 论证 | 交通灯是全人类共享的颜色语言。蓝=进行中来自电脑的"蓝色链接=可以交互"直觉 |
| 偏差 | 紫色（TOP·等）对小孩不够直觉。小孩知道蓝=正在做、黄=在等，蓝+黄混合出紫不够自然。**修正：用蓝色边框+黄色副标题，不用紫色** |

## 二、侧栏交互（详情面板）

### S-01 查看帧详情

| | |
|---|---|
| 小孩直觉 | 我点了一个玩具 → 旁边出现它的说明书 |
| 实现 | 图上点帧 → 右侧栏显示完整信息 |
| 论证 | 主视图+详情面板是邮件/文件管理器的一致模式。小孩用过 iPad 的 Split View 就懂 |
| 偏差 | 无 |

### S-02 进入编辑

| | |
|---|---|
| 小孩直觉 | 我看到字 → 我点一下字 → 出现光标可以改字 |
| 实现 | 点击侧栏正文区域 → 自动进入编辑模式，出现虚线编辑框 |
| 论证 | 在触屏上，点文字=想改文字。小孩在画画 App 里就是这样：点一下就能涂色 |
| 偏差 | 当前需要点 ✎ 按钮进入编辑。多了一步。**修正：点击正文直接进入编辑** |

### S-03 保存修改

| | |
|---|---|
| 小孩直觉 | 我改完了 → 我要告诉大人"我改好了" → 大人问"为什么改？" |
| 实现 | 点"保存修改" → 弹窗问"修改理由" → 填理由后提交 |
| 论证 | "做事要有理由"是小孩在幼儿园学的第一条规则。改了东西→被问为什么→说理由→通过。这完全直觉 |
| 偏差 | 无。但保存按钮在目标区域底部，改了计划后要向上找保存。**修正：保存按钮固定在编辑区顶部** |

### S-04 取消编辑

| | |
|---|---|
| 小孩直觉 | 我画错了 → 我把纸翻过来重新来 / 或者走开不画了 |
| 实现 | 点"✎ 编辑中"按钮切换回只读 / 点其他帧放弃编辑 |
| 论证 | 走开=放弃，这是自然直觉。但目前走开会**丢失所有未保存修改**，没有提示。小孩会觉得"我的画不见了！" |
| 偏差 | **修正：退出编辑时如果有未保存修改，弹确认"放弃修改？/ 继续"** |

### S-05 计划项状态

| | |
|---|---|
| 小孩直觉 | 作业清单上的 ✓ = 做完了、△ = 还没做、● = 正在做 |
| 实现 | `[done]` `[in_progress]` `[ready]` `[blocked]` `[expired]` 文字标签+颜色 |
| 论证 | 清单的直觉。但用英文单词不如用符号直觉。小孩认识 ✓ ✗ ● ▲ 不需要学 |
| 偏差 | **修正：用符号 ✓(done) ⏵(进行中) ○(待做) ⏸(等待) ✗(放弃) + 悬停显示英文全称** |

### S-06 添加子项

| | |
|---|---|
| 小孩直觉 | 我有一个大任务 → 我把它拆成小任务 → 每个小任务写在下面 |
| 实现 | 右键计划项 → "＋ 添加子项" → 弹窗输入内容 |
| 论证 | 缩进=子任务，所有大纲/待办工具的共识。但"右键才能添加"不够直觉——小孩不知道右键有这个功能 |
| 偏差 | **修正：每个计划项末尾直接显示一个小的"＋"按钮（hover 时出现），不需要右键** |

## 三、操作弹窗

### M-01 push 子帧

| | |
|---|---|
| 小孩直觉 | 大人说"先做完这个才能玩" → 我开始做新的事情，但记得做完后回来 |
| 实现 | 弹窗填"标题+目标+理由" → 新帧成为当前焦点，旧帧自动暂停 |
| 论证 | 换任务→旧任务暂停→记住在做什么。这就像小孩换频道时记住之前在看的节目。表单字段用"标题/目标/为什么做"而不是"title/goal/reason" |
| 偏差 | 无 |

### M-02 pop 关闭帧

| | |
|---|---|
| 小孩直觉 | 做完了作业 → 打 ✓ 交上去 / 没做完但不想做了 → 告诉老师为什么 |
| 实现 | 弹窗选择"完成(done)"或"失效(expired)" + 填一句话结论 + 理由 |
| 论证 | 完成/放弃是小孩理解的基本二选一。当前用自由文本填"done"或"expired"不直觉 |
| 偏差 | **修正：两个大按钮"✓ 完成"和"✗ 放弃"，点选而非打字** |

### M-03 暂停帧

| | |
|---|---|
| 小孩直觉 | 我现在不想做这个 → 我先放一边，去做别的 |
| 实现 | 弹窗问"在等什么/为什么暂停" → 填理由后帧变黄 |
| 论证 | "先放一边"=暂停。填"在等什么"就像小孩说"我在等妈妈回来再继续" |
| 偏差 | 无 |

### M-04 恢复帧

| | |
|---|---|
| 小孩直觉 | 妈妈回来了 → 我继续做之前放一边的事 |
| 实现 | 点击"▶ 恢复" → 弹窗预填"从 X 转移到 Y" → 确认后该帧成为焦点 |
| 论证 | 回来继续=恢复。预填理由="妈妈回来了"，小孩只需确认或补充 |
| 偏差 | 无 |

## 四、引用系统（`{{` 自动补全）

### R-01 输入 `{{` 触发

| | |
|---|---|
| 小孩直觉 | 我写了一个特殊符号 → 出现了一个帮助我选择东西的菜单 |
| 实现 | 在可编辑字段输入 `{{` → 弹出候选菜单（帧列表+笔记） |
| 论证 | 类似输入法：打字时出现候选词。小孩用拼音输入法就懂这个模式——打几个字母，出候选，按 Tab 选 |
| 偏差 | 当前只在有 `refable` class 的字段触发，但用户不知道哪些字段有这个 class。**修正：所有正文编辑字段都支持，只在 JSON/reason 等参数字段禁用** |

### R-02 选择候选（Tab/Enter/点击）

| | |
|---|---|
| 小孩直觉 | 出现选项列表 → 用方向键或鼠标选 → 按 Enter 确认（像选电视频道） |
| 实现 | ↑↓ 导航 + Tab/Enter 确认 + 鼠标点击确认 |
| 论证 | 这是所有自动补全/下拉菜单的标准交互。小孩用手机键盘的词语联想就是这个流程 |
| 偏差 | 无 |

### R-03 用 `.` 下钻

| | |
|---|---|
| 小孩直觉 | 我选了一栋房子 → 现在看房子里的房间 → 再看房间里的东西 |
| 实现 | 选帧后自动显示字段列表（.title/.goal/.plan...），选 .plan 后显示索引 [0][1][2] |
| 论证 | 层层深入=进入。像地图从国家→城市→街道→门牌号，每一层都是"点进去看更细的" |
| 偏差 | 当前需要手动打 `.`。**修正：选完候选后自动显示下一层，不需要手动打 `.`** |

### R-04 自动补 `}}`

|---|---|

| 实现 | 选择叶子候选后自动插入 `}}` 并触发预览 |
| 论证 | 输入法在你选词后自动加空格/标点。小孩不需要手动关括号 |
| 偏差 | 无 |

### R-05 悬停候选预览

| | |
|---|---|
| 小孩直觉 | 我把手指放在电视频道号上 → 小屏幕显示那个频道在播什么 |

| 论证 | 预览=先看一眼再决定。就像小孩在零食架前先看包装再决定买哪个 |
| 偏差 | 无 |

### R-06 Esc 关闭菜单

| | |
|---|---|
| 小孩直觉 | 我不想选了 → 我走开 / 按"返回" |
| 实现 | Esc → 关闭候选菜单，回到文字编辑 |
| 论证 | Esc=退出当前操作，所有软件的通用直觉。但**不能把正在编辑的文字也丢了** |
| 偏差 | 当前 Esc 会同时清空整个侧栏（破坏性！）。**修正：Esc 只关菜单，不动其他任何东西** |

### R-07 无效引用处理

| | |
|---|---|
| 小孩直觉 | 我写了别人看不懂的字 → 系统说"看不懂"并问我"你是想写普通文字吗？" |

| 论证 | 纠错+提供出路。就像小孩写错字，老师不只打叉还给正确写法 |

## 六、颜色系统

### 全局色彩语言

| 颜色 | 小孩直觉 | 用途 | 位置 |
|---|---|---|---|
| **蓝** | "正在进行的"（蓝色链接=可以点） | 当前焦点/TOP/活跃路径 | 帧边框、高亮、按钮 hover |
| **黄** | "等一下"（黄灯=等） | Paused 分支、blocked 计划项 | 帧边框、状态标签、警告 |
| **绿** | "做完了"（绿灯=通过） | Done 帧、成功 toast | 帧边框、toast、保存按钮 |
| **红** | "出问题了"（红灯=停） | Expired 帧、错误信息 | 帧边框、toast、错误提示 |
| **金** | "看这里！"（发光的=重要的） | 引用预览、金框 | 预览框、金框、候选高亮 |
| **灰** | "不重要/不能做" | 已关闭帧、禁用按钮 | 降低透明度 |

### 颜色冲突规则

| 规则 | 论证 |
|---|---|
| 状态色 ≠ 交互色 | 帧的边框颜色告诉我它的状态，不是因为我在操作它而变色 |
| 高亮只加效果不改颜色 | 悬停高亮用外框/光晕，不覆盖状态边框。就像小孩穿红衣服，你用手指着它，衣服还是红的 |
| 金色只属于预览 | 引用预览系统独占金色。其他地方不用金色，避免混淆 |
| 一个元素最多两层视觉 | 状态边框（底层）+ 高亮光晕（顶层）。不能同时有三种视觉效果 |

## 七、快捷键汇总

| 键 | 小孩直觉 | 作用 |
|---|---|---|
| **Esc** | "我不要了" | 分层退出：弹窗→预览→菜单→选中→清除 |
| **Tab** | "选这个" | 确认引用候选 |
| **Enter** | "选这个" | 同 Tab |
| **↑↓** | "看上一个/下一个" | 候选导航 |
| **`.`** | "打开它" | 下钻到下一层 |

### Esc 分层退出（最重要的直觉规则）

```
弹窗开着？  → 关弹窗（不关其他任何东西）
预览开着？  → 关预览（不关侧栏）
引用菜单？  → 关菜单（不关编辑，不丢文字）
右键菜单？  → 关菜单
选帧模式？  → 取消选择
什么都没有？→ 清除所有状态
```

**小孩直觉**：一层一层退，像退出房间一样——先出这个房间，再出走廊，最后出大门。不是按一下 Esc 整栋楼塌了。
